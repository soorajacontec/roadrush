# Music

Put an MP3 named exactly **`highway.mp3`** in this folder to use the **Original** music mode.

Recommended free track (CC0 public domain, no royalties, no credit required):

- **"Cool Highway [Remake]"** by MintoDog
- Page: https://opengameart.org/content/cool-highway-remake
- Direct MP3: https://opengameart.org/sites/default/files/cool_highway_remake_bpm140.mp3

Download it, rename it to `highway.mp3`, and commit it with the rest of the project.

Without a file, the game falls back gracefully: **Electronic** mode plays an original soundtrack generated in the browser, and players can still pick their own MP3 with **Load an MP3** in the Garage.
